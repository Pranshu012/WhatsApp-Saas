Both start now.

## If Business Verification is rejected

Normal. Read the reason. Usually a document/detail mismatch or an unconvincing website. Fix and
resubmit — you get multiple attempts. Don't let it block week 2.

## What NOT to do this week

Write code · design the database · choose a frontend library · think about scaling · build a
landing page with animations · set up CI.

**The highest-value work this week is talking to strangers about their WhatsApp problems.** It is
also the least comfortable, which is exactly why it gets skipped.
