# Cross-agent project instructions

All agents must follow [CLAUDE.md](CLAUDE.md), which is the canonical project contract. Before implementing an increment, read its prompt and the referenced architecture documents. Keep work to one increment, use Java 21, Spring Boot 3.x, PostgreSQL 17, Flyway, Maven, and React + Vite, and never introduce undeclared infrastructure.

At the end of each increment, update `docs/IMPLEMENTATION/` and `docs/WhatsApp-SaaS-Product/00-START-HERE/CURRENT-STATUS.md`. Do not commit or push without the user's authorization.
